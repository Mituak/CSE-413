# Two-Sample T-Test

# Description

This project performs a two-sample t-test to determine whether the population means of two datasets are significantly different. Equal variances (pooled) are assumed, with a significance level of α = 0.05.

# Language
Python
# Tools & Libraries
Google Colab
NumPy
SciPy
Matplotlib
# How It Works
Input the two datasets.
Calculate sample means and variances.
Perform a pooled two-sample t-test.
Calculate the t-statistic, degrees of freedom, and p-value.
Calculate the 95% confidence interval.
Compare the p-value with α = 0.05 and make a decision.
# Output
Sample means
Sample variances
Mean difference
t-statistic
Degrees of freedom
Two-tailed p-value
95% confidence interval
Final decision and interpretation

 # Result

Since the p-value is less than 0.05, the null hypothesis (H₀) is rejected. Therefore, the population means are significantly different.
